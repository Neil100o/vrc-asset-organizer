# BOOTH 素材整理器（首版）

本地 Electron 桌面应用：扫描目录中未分类的素材、以网格预览浏览、跳转 BOOTH 搜索，并在确认后移动原文件至分类目录。

## 启动

```powershell
cd 'G:\vrc素材\Booth素材整理器'
npm install
npm start
```

也可直接双击 `启动素材整理器.cmd`。

默认扫描 `G:\vrc素材` 根目录中尚未归类的文件与文件夹；也可在界面中切换目录。首版支持直接显示图片素材预览，其他格式用类型占位卡呈现。点击“在 BOOTH 查找候选”会下载搜索页面所公开的预览图（若页面可读）并可打开对应搜索结果。

新的 VRC 分类标准为：`01_道具`、`02_衣服`、`03_头发`、`04_妆容`、`05_功能插件`、`06_Avatar本体`、`07_场景与地图`、`08_贴图与材质`、`90_待确认`、`91_非VRC内容`。旧的房屋工程分类会保留并在“旧分类”中显示，不会自动移动。“一键检索全部”只处理根目录中尚未整理的素材：查到 BOOTH 商品的素材会按标题关键词归类并自动移动到目标目录；未查到的素材只标记为 `91_非VRC内容`、保留在原位，等待人工确认。右侧详情面板可以手动修改分类、保存标记，并确认移动原文件。未移动素材的分类结果保存在所扫描目录的 `.vrc-asset-organizer.json`。

移动前会显示确认框。若目标目录存在同名文件，会自动附加时间戳，不覆盖现有文件。
