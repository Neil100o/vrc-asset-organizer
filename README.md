# VRC 素材整理器

一个在 Windows 上运行的本地桌面工具，用来浏览、检索和整理 VRChat 素材包。它会扫描压缩包和 Unity 包，尝试在 BOOTH 的 VRChat 分区中查找商品、下载封面缩略图，并在你确认后移动原文件到分类目录。

> 搜索只是辅助，最终的商品、分类与移动操作都由你确认；不会因为一次低置信度匹配而自动归档。

## 适用文件

目前只显示和管理这些素材包：

- `.zip`、`.rar`、`.7z`
- `.unitypackage`

其他文件不会混入素材列表。确认某个包为非 VRC 内容后，它会被移出当前 VRC 素材根目录，放到同级的 `非VRC内容` 文件夹中。

## 主要功能

- 网格缩略图浏览；单击查看右侧详情，双击打开原文件所在位置。
- 扫描根目录和已分类目录，已整理素材也会正常显示在对应分类中。
- 根据文件名、BOOTH 编号、版本号清理后的关键词在 BOOTH 的 VRChat 分区查找候选。
- 候选封面确认、手动填写 BOOTH 商品链接、手动切回分类默认封面。
- 可直接打开 BOOTH 搜索页；模型素材提供 Boothplorer 模型浏览入口，其他素材打开 Boothplorer Items。
- 确认后移动原文件；同名文件自动改名，避免覆盖。
- 分类信息、BOOTH 链接、其他链接和主/附属素材关系都会保存在本地。
- 附属素材可关联主素材，自动沿用主素材封面，并能从主素材详情中打开。
- 支持从资源管理器拖入文件：在分类页拖入会导入当前分类，在待整理页拖入会导入待确认区；可选择移动或复制。

## 分类

默认分类为：

`01_道具`、`02_衣服`、`03_头发`、`04_妆容`、`05_功能插件`、`06_Avatar本体（界面显示为“模型”）`、`07_场景与地图`、`08_贴图与材质`、`09_ERP内容`、`90_待确认`。

“待整理”只显示尚未最终确认的素材；确认分类后的素材会进入相应分类，不再停留在待整理区。

## BOOTH 检索与 LLM（可选）

不开通 LLM 也可以使用完整的普通检索、候选选择和手动链接功能。普通检索会优先使用 BOOTH 编号、完整名称与较强关键词，并自动去掉常见版本号、`beta` 等噪声。

LLM 是可选增强：在“检索”页面为单个素材开启，并在设置中填写兼容 OpenAI Chat Completions 的地址、模型名和 API Key。它只用于扩展中日英/罗马音检索词、推断类别和谨慎比较候选；不确定时会保留候选给你选择，而非强行绑定商品。

手动确认候选后，可以自动加入本地参考库。参考库只会在开启 LLM 检索时参与判断，并且只接受严格的同商品名称证据，不会把“兼容同一模型”的素材当成同一个商品。

## 使用方式

1. 启动后选择 VRC 素材根目录。
2. 在“待整理”中选中素材，点击“在 BOOTH 查找候选”。
3. 确认正确封面；找不到时可手动搜索或粘贴 BOOTH 商品链接。
4. 选择分类，必要时关联主素材或填写其他链接。
5. 点击确认整理，工具才会移动原文件。

## 本地数据

素材记录保存在所选素材根目录的 `.vrc-asset-organizer.json`，包括分类、BOOTH/其他链接、封面选择和附属关系。BOOTH 缩略图缓存在该目录的 `cache` 文件夹中。

这两个位置建议和素材目录一起备份；删除它们不会删除原素材，但会丢失已保存的整理信息和已下载的缩略图。

## 运行源码

需要 Windows、Node.js 和 npm：

```powershell
cd 'G:\vrc素材\Booth素材整理器'
npm install
npm start
```

## 打包为 EXE

```powershell
npm run dist
```

构建产物位于 `dist`：

- `VRC素材整理器 Setup <版本号>.exe`：安装版。
- `VRC素材整理器 <版本号>.exe`：便携版，可直接运行。

## 注意事项

- BOOTH 页面结构、网络状态或访问限制可能影响自动搜索和封面下载；遇到错误时优先使用候选选择或手动链接。
- 工具只移动你确认整理或选择“移动导入”的原文件；不会覆盖同名文件。
- API Key 仅保存在本机应用设置中，不会写入素材目录的分类数据文件。
